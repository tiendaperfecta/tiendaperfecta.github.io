# Listas mensuales de artículos activos de PepsiCo

Acá va el Excel de artículos activos que manda PepsiCo cada mes. Lo lee la página
[Disponibilidad PepsiCo](https://tiendaperfecta.github.io/disponibilidad/).

1. *Add file → Upload files* en esta carpeta.
2. El nombre tiene que llevar el mes: `2026-12.xlsx` o `Disponible de pepsico dic 26.xlsx`.
3. *Commit changes*. En un par de minutos la página muestra la lista nueva.

Del Excel se toma la columna **Material SAP** como código y sólo las filas con **Vigencia = 1**.
Si se sube otro archivo del mismo mes, vale el último.
